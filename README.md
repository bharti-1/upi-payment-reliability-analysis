# UPI Payment Reliability & Revenue Impact Analysis

**Fintech | Product Analytics | SQL | Python | Power BI**

## Project Overview

An end-to-end fintech analytics project investigating UPI payment reliability, transaction failures, and their potential financial impact.

## Business Objective

Understand UPI transaction failure patterns, identify factors associated with failures, quantify failed transaction value, and develop evidence-based recommendations to improve payment reliability.

## Tools & Technologies

- Python: Data generation, cleaning, exploratory data analysis, and statistical investigation
- MySQL: Data storage and SQL-based analysis
- Power BI: Data modeling, DAX, and interactive dashboards
- Git and GitHub: Version control and project documentation

## Project Status

🚧 In progress — currently setting up the project and defining business requirements.

## Project Structure

- `documentation/` — Business requirements, KPI definitions, and methodology
- `data/` — Dataset and data dictionary
- `python/` — Data generation, validation, and analysis
- `sql/` — SQL queries and analytical views
- `powerbi/` — Dashboard and documentation

## Important Disclaimer

This project uses synthetic transaction data. Simulated findings are intended for analytical practice and do not represent actual UPI industry performance or confirmed production-system root causes.
